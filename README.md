One line of the worst possible advice an AI could give, delivered as a tidy, confident security tip: to keep your passwords safe, email them to yourself with the subject line 'my passwords'. The program writes that single line (89 characters) to `/output/entry.txt`, checking it against the competition gate (1–140 characters, not only whitespace) before writing.

## Run it

```sh
ENTRY_OUTPUT=./entry.txt node main.ts
```
